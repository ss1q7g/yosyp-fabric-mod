МАЙНКРАФТ НО ТЫ ЙОСЫП — Fabric 26.3
Описание: почуствуй себя йосыпом играя в майнкрафт

ВАЖНО:
Это ИСХОДНЫЙ ПРОЕКТ мода, а не готовый .jar. Его нужно собрать через Gradle с доступом к интернету и Java 25.
В этой среде я не смог собрать и запустить мод в Minecraft, поэтому совместимость кода с 26.3 не подтверждена.
Для сборки открой папку проекта в IntelliJ IDEA как Gradle-проект и запусти задачу build.
Готовый файл появится в build/libs/.

Что переименовано:
- Эндерман → Эндер Вася
- Ведьма → Чаклун
- Векс → дрончик вася
- Пчела → Бджилки
- Житель → Торгаши
- Тропическая рыба и предмет тропической рыбы → сашими
- Чешуйница → Конфетки
- Ифрит → Ху#ня Бл#дь
- Зомби → охранники
- Кадавр (пустынный зомби) → Пищевод
- Разбойник, поборник, заклинатель и иллюзионист → бригадиры
- Свинья, пиглин, пиглин-брут, хоглин, зоглин → Семья Свиней
- Пещерный паук → Ядовитови паук с и ядом
- Обычный паук → паучара бл#дь
- Булыжник → Эндер камень
- Подсолнух → Кактус
- Алмаз, алмазная руда, глубинная алмазная руда, блок алмазов и алмазные инструменты/броня → варианты «эндерфины»
- Лодки → колесницы
- Достижение «Алмазы!» → «Эндерфины»
- Достижение «Покрой меня алмазами» → «Покрыт эндерфинами»

Тексты достижений меняются только в русском и английском языках. Некоторые названия могут отличаться между версиями игры.
Иконка: положи изображение icon.png в ресурсы вручную, если хочешь использовать его как иконку мода; Fabric не показывает отдельную иконку мода в стандартном меню.


ДОПОЛНЕНИЯ ПО СВЕРКЕ:
- Добавлены переводы названий яиц призыва для мобов из списка.
- Добавлен возможный ключ локализации шкалы рейда event.minecraft.raid = «бригада».
  В Java 26.3 ключи локализации могли измениться; этот ключ нужно проверить в игре.
- В Java лодки существуют как предметы и как сущности. Названия предметов колесниц
  заданы в языковом файле; автоматическое переименование уже поставленной лодки
  в сущность отдельным кодом пока не реализовано.
- Особые имена для зомби-наездника на курице/лошади не реализованы отдельным правилом.
- Не все достижения переименованы: сейчас изменены «Алмазы!» и «Покрой меня алмазами»,
  а также добавлен пробный текст для общего достижения убийства моба. Условия достижений
  не меняются.
- Фотография сохранена как icon.png в корне исходного проекта для справки, но не является
  автоматически подключённой иконкой Fabric-мода.
- Проект не собран и не протестирован в Minecraft. В частности, API вызовы и ключи
  локализации нужно проверить под точную версию Fabric/Minecraft 26.3.
